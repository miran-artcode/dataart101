사이트 소개

교사·보호자·개발자를 위한 페이지입니다. 어떤 기술이 돌아가는지, AI는 어디에만 쓰는지, 학생 데이터는 어디에 저장되는지 적었습니다.

사이트 안에서 돌아가는 기술

색과 이미지그림을 숫자로 바꾸고, 다시 그림으로

  • 대표색 찾기 (K-means 군집)

    그림 속 수만 개의 픽셀을 비슷한 색끼리 K개 무리로 묶고, 각 무리의 평균색을 대표색으로 씁니다.

    색 군집 스튜디오, 알고리즘 분석실, 첫 화면 데모

    원리 보기

    첫 중심은 서로 멀리 떨어지게 고르는 k-means++ 방식으로 정하고, 최대 24번 반복해 중심을 다듬습니다. 난수에 시드를 쓰기 때문에 같은 그림·같은 설정이면 언제나 같은 결과가 나와, 학생끼리 결과를 비교할 수 있습니다.

    색 거리는 RGB와 LAB 중에서 고릅니다. LAB은 사람 눈이 느끼는 색 차이에 더 가깝습니다. js/kmeans.js js/analysis.js

  • 그림을 점으로 바꾸기

    그림에서 점 수천 개를 뽑아 각 점에 가장 가까운 대표색을 칠합니다. 밝은 곳, 어두운 곳, 윤곽선 쪽에 점을 더 많이 놓을 수도 있습니다.

    원리 보기

    밝기·어둡기·윤곽 세기(Sobel)로 가중치 지도를 만든 뒤 그 비율대로 위치를 뽑습니다. 점마다 위치, 대표색 번호, 밝기, 윤곽 세기를 저장해 움직임과 3D 깊이에 다시 씁니다. js/analysis.js

  • 일곱 가지 분석 알고리즘

    대표색 외에도 색 단순화(포스터화), 명암 단순화(노탄), 윤곽선 찾기, 미디언 컷, 모자이크, 구도 분석으로 같은 그림을 다르게 읽습니다.

    알고리즘 분석실

    원리 보기

    기본 네 가지(K-means, 포스터화, 노탄, Sobel 윤곽)와 심화 세 가지(Median Cut, 모자이크, 무게중심·삼분할 구도)로 나뉩니다. 각 결과 옆에 차트와 한계 메모 칸이 붙습니다. js/algos/algorithms.js

  • 색채 조화와 차트

    대표색이 색상환에서 보색·삼각·유사 관계인지 찾아 주고, 색 비율을 도넛·막대·히스토그램 등 여섯 가지 차트로 보여 줍니다.

    원리 보기

    색을 HSL로 바꿔 색상 각도 차이로 조화 관계를 판정합니다. 차트는 외부 라이브러리 없이 Canvas 2D로 직접 그려서 인터넷이 없어도 나옵니다. js/harmony.js js/charts.js

  • 움직이는 점

    대표색 점들이 마우스를 피하거나 따라오고, 소리가 커지면 흔들리거나 흩어집니다. 밝기를 깊이로 바꾸면 3D 조각처럼 돌려 볼 수 있습니다.

    원리 보기

    수만 개의 점을 빠르게 그리려고 일반 배열 대신 Typed Array를 씁니다. 그리기에는 p5.js를 쓰며, 사이트 안에 함께 들어 있어 오프라인에서도 작동합니다. 저장된 설정으로 갤러리와 키오스크에서 같은 움직임을 다시 재생합니다. js/particles.js js/player.js vendor/p5.min.js

소리목소리와 음악을 데이터 표로

  • 소리를 숫자로 바꾸기

    5~20초 동안 녹음하면, 0.15초마다 소리의 크기와 낮은음·중간음·높은음의 세기, 가장 센 음높이를 표(CSV)로 만듭니다. 이 표를 그대로 데이터 점 스튜디오로 보낼 수 있습니다.

    소리 스튜디오, 색 군집 스튜디오(마이크로 연주)

    원리 보기

    브라우저에 들어 있는 Web Audio API의 AnalyserNode(FFT 크기 1024)로 주파수를 나눕니다. 음량은 RMS로, 음높이는 에너지가 가장 큰 주파수(Hz)로 계산합니다. 녹음 원본은 저장하지 않고 숫자 표만 씁니다. js/studio-sound.js js/audio.js

AI쓰는 곳과 쓰지 않는 곳

  • 사진 속 사물 찾기

    사진을 넣으면 AI가 사람, 컵, 의자처럼 80가지 사물을 찾아 상자와 이름을 붙입니다. 명화 앞에서 AI가 무엇을 못 보는지도 확인합니다.

    객체 감지

    원리 보기

    TensorFlow.js와 COCO-SSD 모델(lite_mobilenet_v2)을 처음 쓸 때 내려받아 브라우저 안에서 계산합니다. 사진은 서버로 올라가지 않습니다. 모델을 받지 못하면 미리 준비한 예시 결과로 넘어갑니다. js/studio-object.js

  • 감상 코치

    작품을 보고 정답이나 칭찬 대신 "왜 그렇게 느꼈는지" 근거를 묻는 질문만 합니다.

    원리 보기

    기본은 규칙에 따라 질문을 고르는 방식이라 AI도 인터넷도 쓰지 않습니다. 선생님이 교사 대시보드에서 켰을 때만 Claude(Anthropic API) 또는 학교가 지정한 중계 서버를 부릅니다. 요청은 분당 5회로 제한되고, 실패하면 규칙 기반 질문으로 돌아갑니다. API 키는 그 기기의 브라우저에만 저장됩니다. js/coach.js js/ratelimit.js

  • 작품 해설(도슨트)AI 아님

    학생이 적은 의도와 설정값을 읽어 해설 문단을 만듭니다. AI처럼 보이지만 미리 짜 둔 문장 틀에 값을 채워 넣는 방식입니다.

    원리 보기

    의도, 사용한 데이터, 매핑, K와 점 개수를 문장 틀에 넣어 조립합니다. 같은 입력이면 같은 문장이 나옵니다. 페이지 곳곳의 설명 팝업과 힌트, 낱말 사전도 모두 미리 써 둔 글입니다. js/docent.js js/explain.js js/guide.js

기록과 전시저장하고 공유하기

  • 작품 저장

    작품, 피드백, 작업 노트, 퀴즈를 저장합니다. 학교 저장소에 연결되어 있으면 반 친구들과 공유되고, 연결이 끊기면 내 기기에 저장됩니다.

    원리 보기

    기본은 브라우저 저장소(localStorage)이고, 설정 파일이 있으면 Firebase Firestore를 씁니다. 주소 끝에 ?local=1을 붙이면 기기 저장만 씁니다. 교사 대시보드에서 전체를 JSON 파일로 내보내고 다시 가져올 수 있습니다. js/store.js config/cloud-config.js

  • QR 감상과 키오스크

    전시 화면에 작품마다 QR 코드가 뜨고, 관람객은 로그인 없이 휴대폰으로 작품을 보고 비평을 씁니다.

    원리 보기

    키오스크는 9초마다 작품을 넘기며, 방향키와 스페이스바로 직접 넘기거나 F로 전체 화면을 켭니다. 비평은 펠드먼의 4단계(서술·분석·해석·판단)를 따릅니다. js/exhibit.js js/qr.js js/work.js

  • 작업 노트

    과정과 버전, 성찰을 시간 순서로 기록하고, "AI가 도운 것"과 "내가 결정한 것"을 나눠 적습니다.

    작업 노트

내 데이터는 어디에 저장되나요

굵은 테두리: 기기 밖으로 나가지 않음 · 점선: 선생님이 켰을 때만

내 기기 안

이 컴퓨터나 휴대폰의 브라우저에만 저장됩니다.

  • 로그인 정보(이름, 반, PIN)
  • 녹음한 소리(숫자 표로 바꾼 뒤 원본은 버림)
  • 사물 찾기에 넣은 사진
  • 화면 테마 같은 설정

다른 기기에서는 다시 로그인 정보를 만들어야 합니다.

학교 저장소

Firebase Firestore. 반 친구들과 공유하기 위한 곳입니다.

  • 전시한 작품(표시 이름, 의도와 근거, 설정, 이미지)
  • 피드백과 비평
  • 작업 노트
  • 퀴즈와 답

사이트 주소를 아는 사람은 누구나 볼 수 있습니다. 표시 이름은 실명 대신 이니셜이나 별명을 고르세요. 단원이 끝나면 선생님이 정리합니다.

AI 감상 코치

기본은 꺼져 있습니다. 선생님이 켰을 때만 외부로 보냅니다.

  • 작품의 대표색과 설정값
  • 학생이 쓴 작품 의도

Anthropic의 Claude API 또는 학교가 지정한 중계 서버로 전송됩니다. 꺼져 있으면 아무것도 나가지 않습니다.

이렇게 만든 이유

  • 인터넷이 끊겨도 수업은 계속됩니다

    설치나 서버 없이 파일만 열면 시작됩니다. 명화를 못 불러오면 비슷한 그림을 직접 그려 대신하고, 저장소가 끊기면 기기에 저장합니다.

  • AI는 정답을 주지 않습니다

    감상 코치는 질문만 하고, 판단은 학생이 합니다. AI가 도운 부분은 작업 노트에 따로 표시합니다.

  • 분석의 한계를 묻습니다

    모든 알고리즘은 그림을 줄여서 봅니다. 결과마다 무엇이 사라졌는지 적는 칸이 있습니다.
